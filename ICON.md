# Launcher artwork

`app/src/main/res/drawable-nodpi/app_icon.png` is the selected SUV artwork, generated with the built-in OpenAI image-generation tool following the owner's direction. No original Mitsubishi artwork was used. The image is included as part of the GPL-3.0-or-later project to the extent rights apply. It is not an official vehicle-manufacturer mark.

The Android adaptive icon uses the same image with inset padding and a forest-green background. The source PNG is also displayed in the README. No image-generation service is used at runtime.

Generation prompt:

> Use case logo-brand. Create a square Android app icon for Open PHEV. User direction: a sleek SUV silhouette on forest green. Premium minimalist flat graphic: elegant ivory side silhouette of a modern mid-size SUV, wheels and windows cleanly cut out in dark forest green, one subtle mint electric accent integrated along lower body. No windscreen symbol, no lightning bolt as main motif. Full bleed rich forest-green background with extremely subtle depth. Central SUV occupies only central 60% width and 38% height, generous padding for circular Android adaptive icon cropping. Recognisable bold silhouette at tiny app-icon size. No text, no letters, no Mitsubishi logo or other brand, no watermark, no outer rounded square, no phone mockup. Square image.
